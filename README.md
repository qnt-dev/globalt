# GLOBAL TRIUMPH, дизайн «Затмение»

Концепт сайта для соискателей, работодателей и заказчиков маркетинга. Страница одна, все ресурсы встроены в `index.html`.

## Открыть

```bash
python -m http.server 4391 --bind 127.0.0.1
```

Затем откройте http://127.0.0.1:4391/. Файл `index.html` также открывается двойным щелчком, без сервера.

## Собрать и проверить

Нужны Python и Chrome, пакеты: `pip install fonttools brotli playwright pillow`.

```bash
python src/build.py
```

```bash
python src/test.py
```

Проверка требует запущенного сервера на порту 4391.

## Что где лежит

- `src/app.js`, `src/style.css`, `src/body.html`: код страницы. Вакансии и объекты записаны в начале раздела «МИР 1» в `app.js`.
- `src/build.py`: сборка в `index.html`.
- `src/test.py`, `src/look.py`, `src/motion.py`: проверки и снимки в Chrome.
- `assets/`: логотип, знак, шрифт, фото.
- `maket/`: утверждённые статичные макеты, исходные снимки и список их источников.
- `NOTES.txt`: история правок и ограничения. Все объекты, суммы и условия выдуманы, формы ничего не отправляют.
