# GLOBAL TRIUMPH

Концепт сайта для соискателей, работодателей и заказчиков маркетинга. Страница одна: `index.html` и папка `assets` рядом с ней.

## Открыть

```bash
python -m http.server 4391 --bind 127.0.0.1
```

Затем откройте http://127.0.0.1:4391/. Нужен сервер: карты Земли на главной страница грузит из `assets/earth`, а без сервера браузер не даёт WebGL брать картинки с диска.

## Собрать и проверить

Нужны Python и Chrome, пакеты: `pip install fonttools brotli playwright pillow`.

```bash
python src/build.py
```

```bash
python src/test.py
```

Проверка требует запущенного сервера на порту 4391.

## Что где лежит

- `src/app.js`, `src/style.css`, `src/body.html`: код страницы. Главная (Земля, разделы, переход «Распад») в начале `app.js`. Вакансии и объекты записаны в начале раздела «МИР 1».
- `src/brend.*`, `src/smm.*`, `src/reklama.*`, `src/site.*`: примеры на станциях мира «Клиенты» (Бренд, SMM, Реклама, Сайт). Сборка ставит их перед `app.js` и `style.css`. Начало мира («Сто одинаковых», план из четырёх этапов) и меню справа живут в `app.js`.
- `src/reel.*`, `src/smm-keys.js`: лента профессий под стеной вакансий и поле клавиш станции SMM.
- `src/sonar.js`: сетка-сонар под чёрными надписями станций (по мотивам Sonar Grid, NIMA MZ, 21st.dev, MIT).
- `src/build.py`: сборка в `index.html`.
- `src/test.py`, `src/look.py`, `src/motion.py`: проверки и снимки в Chrome. Снимки пишутся в `review/`, в git она не идёт.
- `assets/`: логотип, знак, шрифты (Science Gothic, Tektur с лицензией OFL), фото вакансий и людей (`photo`), карты Земли (`earth`), фото кофейни ZERNO (`zerno`).
- `PHOTOS.txt`: источники всех фото, карт и шрифта Tektur.
- `NOTES.txt`: история правок и ограничения. Все объекты, суммы и условия выдуманы, формы ничего не отправляют.
